# 字规 ZiGui —— 参数化中文字体生成引擎（原型）

> 确认一套**笔画规范特征元素**（起笔/收笔顿角、拐角处理、横竖线宽对比、
> 撇捺收锋锥度、钩长等），由规则引擎自动展开成整套字体。
> 字形骨架与风格参数完全解耦：同一套骨架，换一份参数文件即生成一套新字体。

## 效果

`dist/specimen.png` 为同一套骨架在两组参数下的对照样张：

| 风格文件 | 输出 | 特征参数差异 |
|---|---|---|
| `styles/heiti.json` | `dist/heiti.otf` | 横竖等宽、平头起收笔、直角折 |
| `styles/songti.json` | `dist/songti.otf` | 横细竖粗、顿笔起收、折角顿角、撇捺出锋 |

## 使用

```bash
pip install fonttools pillow
python -m zigui                    # 构建 styles/ 下全部风格 → dist/*.otf + 样张
python -m zigui styles/songti.json # 只构建指定风格
```

生成的 OTF 为标准字体文件，可直接安装到系统中使用。

## 架构

```
骨架层  zigui/glyphs.py    字形 = 笔画规格列表（仅中轴线坐标，与风格无关）
笔画层  zigui/strokes.py   横竖撇捺点提折钩 → 按参数展开为轮廓
几何层  zigui/geometry.py  曲线采样、骨架→轮廓(ribbon)展开、方向归一
构建层  zigui/builder.py   fontTools 写出 OTF（CFF 轮廓）
校对层  zigui/preview.py   不依赖系统字体栈，直接渲染样张 PNG
```

关键取巧：所有轮廓统一为顺时针方向，配合字体的非零环绕填充规则，
笔画交叠处自然合并，无需多边形布尔运算。

## 风格参数（即"规范特征元素"）

| 参数 | 含义 |
|---|---|
| `h_width` / `v_width` | 横/竖线宽（对比度） |
| `heng_tilt` | 横画右端抬升量 |
| `cap` | 起收笔风格：`flat` 平头 / `dun` 顿笔 |
| `dun_size` | 顿角尺寸（相对横宽） |
| `corner` | 折角风格：`miter` 直角 / `bump` 顿角 |
| `pie_tip` | 撇收锋处宽度比（越小越尖） |
| `na_peak` | 捺最宽处相对竖宽（捺脚铺开程度） |
| `hook_len` | 钩长 |

## 法律定位

本引擎不参照、不训练、不演绎任何受版权保护的字体——字形完全由
自有骨架数据 + 用户设定的参数规则生成，独创性链条清晰，
生成的字库可作为计算机软件著作权/美术作品申请登记。
